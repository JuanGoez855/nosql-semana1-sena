## 📌 Descripción del Proyecto
Este repositorio contiene la solución completa de la **Semana 1 de NoSQL**. El objetivo principal es diagnosticar saberes previos en manejo de datos, comparar familias de bases de datos NoSQL frente al modelo relacional, definir las reglas de negocio y patrones de consulta del caso integrador, y validar un entorno local de desarrollo con **MongoDB** y **BSON**.
